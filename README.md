# yuelong88888888-cloud.github.io

这是我的个人网站项目，用于向 GitHub 用户和其他访客介绍我自己，并集中展示我的科研经历、实习经历、项目成果、学术出版物和简历。

访问网站：[https://yuelong88888888-cloud.github.io](https://yuelong88888888-cloud.github.io)

## 网站主要结构

- **首页（Home）**：个人简介、照片和最新动态。
- **项目（Projects）**：展示参与或完成的代表性项目。
- **出版物（Publications）**：整理学术论文及其他研究成果。
- **个人简历（CV）**：提供个人简历 PDF，方便在线查看或下载。

## 仓库结构

```text

├── index.html                 # 网站首页
├── projects/                 # 项目展示页面
├── publications/             # 出版物与研究成果页面
├── files/Zyl.pdf              # 个人简历
├── assets/
│   ├── css/style.css         # 网站样式
│   └── images/               # 个人照片与项目图片
├── _data/                    # 新闻动态、出版物等结构化数据
├── _includes/                # 页头、页脚等可复用组件
├── _layouts/                 # Jekyll 页面布局模板
└── _config.yml               # Jekyll 网站配置
```

本网站通过 GitHub Pages 发布，并使用 Jekyll 组织页面内容。
